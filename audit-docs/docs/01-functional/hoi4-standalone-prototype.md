# Hearts of Iron IV: отдельный прототип, не подтверждённая интеграция NeuroMita Core

**Статус:** `EXPERIMENTAL / UNRESOLVED` для самостоятельного запуска; `ACTIVE` в основной композиции **не подтверждён**. **Уверенность:** `CONFIRMED` в обнаруженных исходниках о наличии скриптов и отсутствии найденных импортов в основной `src`; `INFERRED` о недостижимости из штатного Core; `UNKNOWN` относительно использования вручную пользователем.

## Назначение и фактическая граница

В `src/connetors/hoi4/` находятся самостоятельный мост к игре, мод Clausewitz и обёртка консольных чит-команд. Мост предполагает связь **HOI4 mod → game.log → Python log tailer → очередь событий → демонстрационная логика → очередь команд → Win32 keyboard injection → консоль HOI4**. Наличие этих файлов само по себе **не** доказывает наличие зарегистрированной функции NeuroMita, доступной персонажу, LLM tools, Unity или главному GUI.

Проверка `rg -n 'hoi4|Hearts of Iron' src --glob '!**/hoi4/**'` обнаружила только ссылку в `src/ProjectStructureForLLM.txt:163`, но не вызов/импорт/регистрацию основным приложением. В `hoi4_server.py:151-162` запуск выполняется только под `if __name__ == '__main__'`; `hoi4_cheats.py:169+` содержит отдельный тестовый запуск. Поскольку возможны внешние ярлыки и динамическая загрузка, это не является абсолютным доказательством отсутствия пользовательского сценария; категорично присваивать `LEGACY` нельзя.

## Capability: HOI4 event bridge (`CAP-HOI4-EXPERIMENTAL-001`)

**Источники:** `src/connetors/hoi4/hoi4_server.py:9-162`, `src/connetors/hoi4/Mod/neuro-mita/Events/mitanet_commands.txt`, `.../mitanet_pulse.txt`, `.../common/on_actions/mitanet_on_actions.txt`.

1. `LogTailer` ждёт `%USERPROFILE%/Documents/Paradox Interactive/Hearts of Iron IV/logs/game.log`; начинает чтение с конца файла и каждые ~50 мс проверяет добавленные строки (`hoi4_server.py:12-62`). При смене inode переоткрывает файл, но **не** подтверждено корректное восстановление при truncate/replacement на всех Windows-файловых системах.
2. Строка, содержащая `MITA_OUT`, разделяется по первому вхождению; остаток парсится как JSON и попадает в очередь. Не-JSON событие печатается и отбрасывается. Проверки схемы/version/event id/correlation отсутствуют (`hoi4_server.py:50-62`).
3. Основной цикл вызывает именно `dummy_ai_logic`: `heartbeat` → `give_pp(50)`, `war` → `build_factory(state=70,count=2,tag=actor_tag|GER)`, остальные события игнорируются (`hoi4_server.py:109-159`). **LLM здесь не вызывается.**
4. `ConsoleInjector` независимо читает очередь, распознаёт только `build_factory` и `give_pp`; `None` — sentinel остановки worker, но главный цикл бесконечный и не посылает sentinel при обычном KeyboardInterrupt (`hoi4_server.py:65-107,151-162`). Команды выполняют побочные эффекты в игре, возможны ложный фокус окна и конфликт ввода пользователя.
5. Мод содержит события `mitanet.10` (war), `.11` (focus), `.20` (day pulse) и `.999` (action). Однако `on_declare_war` и `on_focus_complete` в `mitanet_on_actions.txt` имеют **пустые** `events = { }`, так что путь war/focus от текущих hooks не доказан. `on_daily` вызывает `.20`; её счётчик формирует `heartbeat` по трёхдневному порогу.
6. Скрипт `.999` использует глобальный флаг и переменные для условного строительства и автозавершения фокуса. Подтверждается лишь текстовая логика скрипта, не запуск / корректность DLC/game-script API.

**Вход:** события игрового лога / команды через `queue.Queue`. **Выход:** Win32 keyboard events и игровые console commands. **Состояния:** текущая позиция tailer, две process-local очереди, foreground окно и глобальные переменные игры. **Ошибки:** отсутствующий log/game window, битый JSON, рассинхронизация фокуса и клавиатуры, пропущенные записи при ротации, непринятый schema variant, отсутствие graceful shutdown. **Восстановление:** после перезапуска tailer начинает с конца — старые события не replay.

## Capability: ручной набор команд (`CAP-HOI4-EXPERIMENTAL-002`)

**Источники:** `src/connetors/hoi4/hoi4_connector.py:1-176`, `src/connetors/hoi4/hoi4_cheats.py:7-166`.

- Поиск окна использует `psutil` для процесса `hoi4`, `win32gui.EnumWindows`, `win32process`, восстановление свёрнутого окна и `SetForegroundWindow`; ввод команд — Win32 keybd_event / Unicode char sequence, консольная клавиша, backspaces, enter (`hoi4_connector.py`). Это **Windows-specific** и зависит от локальной интерактивной сессии.
- Набор обёрток: политвласть, стабильность, поддержка войны, XP, manpower, строительные команды, дипломатия, annex, peace, civil war, research, переключение страны. Есть `_cheat_map` и `execute_cheat`, но импортов из основной LLM tool registry не найдено (`hoi4_cheats.py:63-166`).
- `_detect_player_tag()` документирует предполагаемый `whoami`/log, но реально спит и подставляет **`GER`** (`hoi4_cheats.py:12-23`). `switch_to()` восстанавливает *предполагаемый* tag через `finally`; ложный tag может перевести игрока не туда (`hoi4_cheats.py:39-59`).
- `instant_construction(enable)` переключает `ic`, не проверяя `enable`; аналогично `focus_autocomplete` не проверяет аргумент. Эти параметры нельзя считать строгими set-state контрактами (`hoi4_cheats.py:101-106`).
- `hoi4_cheats.py:7` импортирует `from hoi4_connector import ...` без пакетного префикса: работоспособность зависит от `sys.path`/каталога запуска, не проверялась.

## Требование к будущему Rust Core

Не включать HOI4 в список **обязательного паритета активного NeuroMita** до подтверждения одного из двух фактов: (а) реального штатного entrypoint/feature registration; (б) явного решения владельца сохранить отдельный инструмент как функциональность нового продукта. При таком решении функциональный контракт нужно переописать на уровне «взаимодействие с игровыми событиями/командами», **не** на уровне копирования клавиатурной инъекции или placeholder `dummy_ai_logic`.

## Проверки для продолжения

- Проверить внешние launcher/config, не вошедшие в ZIP, и запуск scripts пользователями.
- Проверить правильность фактических HOI4 event hooks в установленном моде, не только в исходных текстах.
- Определить, является ли сценарий поддерживаемым продуктовым функционалом или прототипом.
- Не запускать скрипты ради аудита без изоляции: они отправляют реальные игровые команды.
