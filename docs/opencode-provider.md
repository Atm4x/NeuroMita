# OpenCode в NeuroMita

В настройках API доступны два пункта: **OpenCode Zen** и **OpenCode Go**
(включая Go Plus). Формат API и адрес запроса выбираются автоматически по модели.
Создайте пресет по шаблону, вставьте API-ключ из [Console](https://opencode.ai/console),
нажмите «Получить модели» и выберите модель. Ответ выбранной модели проверяется
запросом в песочнице.

## Доступ и ограничения

- Console / Zen: оплата запросов с баланса. Бесплатные chat-модели доступны
  для экспериментальной попытки, включая запрос без ключа. Они помечены в
  каталоге; NeuroMita не блокирует их локально и не подменяет идентичность клиента.
  Документация ограничивает бесплатный чат клиентом OpenCode; прямой запрос может
  вернуть 403 или 429. Успешная бесплатная генерация из другого клиента не
  гарантируется. У провайдера нет общей метки FREE: доступ зависит от модели.
- Go / Go Plus: подписка с квотами и API-ключом. Промо-модели с суффиксом `-free`
  помечаются бесплатными, но могут требовать подписки, допустимого региона и
  разрешений workspace. Это не обещание бесплатного доступа без подписки.
- Go предназначен для типичного трафика coding agents. Применимость подписки
  к игровым диалогам NeuroMita не подтверждена. Клиент честно представляется
  `NeuroMita/1.0`; маскировки под OpenCode нет.
- Для Go передаётся `x-opencode-session`: стабильный идентификатор персонажа
  в пределах запуска приложения; разные персонажи получают разные значения.
  При отсутствии контекста используется общая сессия текущего запуска.
- Privacy-настройки workspace и регион могут ограничивать отдельные модели.
  Contributor-модели могут использовать запросы для обучения.

## Каталог и проверка

`GET /inference/v1/models` и `GET /inference/go/v1/models` возвращают публичные
каталоги. Успешная загрузка **не проверяет** ключ, баланс, наличие подписки,
остаток квоты или доступ к конкретной модели. UI сообщает об этом прямо.
Автоматическая генерация при загрузке каталога не выполняется.

Каталог объединяет поддерживаемые форматы API. GPT, Grok и Muse
используют Responses, Gemini — generateContent, поддерживаемые открытые
модели — Chat Completions. Различия Console и Go учитываются: например,
MiniMax M3 использует Chat Completions в Console и Anthropic Messages в Go.
Неизвестные семейства не добавляются до подтверждения совместимости.
Если OpenCode меняет формат существующей модели, таблицу совместимости
`src/presets/opencode.py` потребуется обновить.

Anthropic Messages (Claude, большинство Qwen и некоторые MiniMax в Go) и
System One (Jev) в текущей интеграции не поддерживаются и исключены из списка.
Ручной выбор несовместимого
семейства выдаёт понятную ошибку без сетевого запроса.

Сохранённые пресеты из первоначального варианта с шестью шаблонами переносятся
в два общих шаблона с сохранением ключа и модели. После обновления перезапустите
приложение и нажмите «Получить модели», чтобы обновить сохранённый каталог.

Актуальные условия и список моделей:
[Console models](https://opencode.ai/v2/docs/console/models/),
[Inference API](https://opencode.ai/v2/docs/console/api/inference/),
[Go](https://opencode.ai/v2/docs/console/go).
