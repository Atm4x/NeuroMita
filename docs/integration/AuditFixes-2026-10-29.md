## Ограничения и дальнейшая приёмка

Ручной Play Mode, совместный запуск Unity ↔ Python с LLM/голосом, реальный захват экрана и Windows build не выполнялись. Проверки capture использовали подставленный источник, а не снимки рабочего стола. Перезапуск Python проверен через новый менеджер каталога; полноценный запуск GUI/БД приложения остаётся сценарием приёмки.

Старые snapshots без spatial поддерживаются для единичного масштаба и вертикальной позы. Старые snapshots после изменения размера/наклона отклоняются: потерянные ранее camera/gravity данные нельзя достоверно восстановить.

Мебель сохраняет конечное open/closed, а не фазу анимации. Её ID вычисляется из пути сцены, иерархии и типа компонента: переименование/перестановка иерархии при изменении содержимого мира требует миграции. Это не поддержка произвольной перестройки сцены между сохранением и загрузкой.

Портальные render-тесты сохраняют известные предупреждения `Releasing render texture that is set to be RenderTexture.active`; они не исправлялись в рамках F01–F07.
