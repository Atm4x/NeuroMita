# Поиск в NeuroMita — какие варианты есть и как включить

У Миты есть несколько способов «сходить в интернет». Они не взаимоисключающие —
можно включить сразу несколько, модель сама выберет подходящий. Ниже — от самого
простого к продвинутому.

Все настройки — в разделе **«Настройки взаимодействия с моделью»** (если не указано иное).

## 1. Встроенный поиск модели (grounding) — рекомендуется для Gemini

Галка **«Встроенный поиск модели»** (`NATIVE_WEB_SEARCH`).

Модель ищет сама, ничего настраивать не надо. Источники показываются прямо в чате
(блок «🔍 источники» в структурной панели ответа).

- **Gemini** — Grounding with Google Search. Есть бесплатная квота
  (Gemini 3.x: ~5000 запросов/мес; 2.5: ~1500/день), дальше платно.
  На Gemini 2.5 и старше поиск несовместим со строгим структурированным ответом —
  приложение автоматически переходит на «мягкий» JSON, так что всё продолжает работать.
- **OpenRouter** — плагин web поверх любой модели (платно, ~$4/1000 результатов).

Другие провайдеры (обычный OpenAI/локальные) этот механизм не поддерживают — используйте
тулы ниже.

## 2. Тулы поиска (function calling)

Требуют включённого **«Вызов инструментов» (`TOOLS_ON`)** и работают на моделях,
поддерживающих tools/structured output.

### web_search — DuckDuckGo (бесплатно, без ключа)
Галка **«Поиск в интернете»**. Мета-поиск по нескольким движкам, регион по умолчанию `ru-ru`.
Качество среднее (поисковики душат ботов), но бесплатно и без настройки.

**Апгрейд через SearXNG.** Если укажете **«SearXNG URL»** (`WEB_SEARCH_SEARXNG_URL`,
например `http://localhost:8080`), `web_search` будет ходить в ваш инстанс SearXNG
(качественнее и приватнее), а на DuckDuckGo откатываться только при сбое. Инстанс должен
отдавать JSON (`format=json`); публичные инстансы часто это блокируют — лучше поднять свой.
Как поднять (Docker): <https://docs.searxng.org/admin/installation-docker.html>

### wikipedia_search — Википедия (бесплатно, без ключа)
Галка **«Википедия»**. Быстрые фактические выжимки со ссылками (кто/что/когда).
Язык — `ru` с фолбэком на `en` (можно сменить настройкой `WIKIPEDIA_LANG`). Без лимитов.

### tavily_search — Tavily (нужен ключ, есть free-tier)
Галка **«Tavily поиск»** + поле **`TAVILY_API_KEY`**. Поиск, заточенный под ИИ: чистые
выжимки и опциональный краткий ответ. Точнее `web_search`. Бесплатный лимит ~1000/мес.
Ключ — на <https://app.tavily.com/home>

### brave_search — Brave Search (нужен ключ, есть free-tier)
Галка **«Brave поиск»** + поле **`BRAVE_API_KEY`**. Свой независимый индекс (не Google),
приватный, качество хорошее. Бесплатный лимит ~2000/мес.
Ключ — на <https://api-dashboard.search.brave.com/>

### google_search — Google Custom Search (нужны ключ + CSE)
Галка **«Google поиск»** + поля **`GOOGLE_API_KEY`** и **`GOOGLE_CSE_ID`**.
Официальный API Google, но урезанный (100 запросов/день бесплатно) и требует настройки
Custom Search Engine. Ключ — на <https://console.cloud.google.com/apis/credentials>,
CSE ID — на <https://programmablesearchengine.google.com/controlpanel/all>

### web_reader — чтение страниц
Галка **«Чтение страниц»**. Не ищет, а скачивает и чистит конкретную страницу по URL
(через Jina Reader). Хорошо в паре с поиском: найти ссылку → прочитать.

## Что выбрать

- **Только Gemini** → включите встроенный поиск (п.1), больше ничего не нужно.
- **Бесплатно и без ключей на любой модели** → `web_search` + `wikipedia_search`.
  Хотите заметно лучше — поднимите SearXNG и впишите его URL.
- **Нужно максимальное качество** → `tavily_search` (ключ) как основной, `web_search`
  как бесплатный фолбэк.
- **Фактические вопросы** (даты, персоны, определения) → `wikipedia_search` часто
  точнее и быстрее веб-поиска.

## Единый формат выдачи

Все поисковые тулы возвращают JSON со списком объектов `{title, url, snippet}`
(у `tavily_search` дополнительно может быть `answer`). Это упрощает модели разбор
результатов независимо от источника.
