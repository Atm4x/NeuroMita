Write EXECUTABLE Lua code. Return ONLY ```lua\n...\n```.

- Code must be READY TO RUN — no placeholder comments like "replace with..."
- Use actual unit IDs from the request: Footman=hfoo, Knight=hkni, Archer=hhes, etc.
- Get coordinates from playerCapital[playerId]: GetUnitX(cap), GetUnitY(cap)
- Player(playerId - 1): playerId from 1 to 24
- If request is unclear — return return "error: clarify"

## Examples

```lua
end
```
